# Desktop handoffs

Historical task briefs for the Rust/GTK4 desktop, one per completed milestone:
the initial player, the reference-based UI redesign, and the queue/lyrics pass.

They are kept as the record of the constraints those passes had to preserve (bridge
bounds, stale-result rejection, GLib ownership, lyric timing), not as current
instructions. Behaviour and commands live in `desktop-rust/README.md`.
